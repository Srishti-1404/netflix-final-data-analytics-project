# Netflix Final Data Analytics Project

## Project Overview

This project is an end-to-end data analytics case study based on a public Netflix Movies and TV Shows dataset. It combines data cleaning, exploratory data analysis, data visualization, and interactive dashboard development.

## Problem Statement

The goal is to understand the Netflix content catalog, examine its characteristics, identify useful trends and patterns, and communicate the findings through visualizations and an interactive dashboard.

## Dataset Information

The dataset includes information such as title, content type, director, cast, country, date added, release year, rating, duration, categories, and description.

Dataset Source: https://docs.google.com/spreadsheets/d/1SKwDhdhDAD9WRk17A-uMHsF37roTjN6uJ2LRXy7TkJg/edit?usp=sharing

## Task 1: Data Cleaning and Preparation

- Examined missing and unknown values.
- Checked for duplicate records and duplicate IDs.
- Reviewed data types and inconsistent values.
- Prepared a cleaned dataset for analysis.

## Task 2: Exploratory Data Analysis

- Compared Movies and TV Shows.
- Explored country and category distributions.
- Examined release-year trends and content ratings.
- Analyzed movie durations.
- Created charts and descriptive statistics using Python, Pandas, and Matplotlib.
- Documented findings based on the actual analysis results.

## Task 3: Interactive Dashboard

Created a Power BI dashboard featuring:

- KPI cards for total titles, Movies, and TV Shows.
- Content type comparison.
- Release-year trends.
- Content rating and category visualizations.
- Interactive filters for country, release year, and content type.
